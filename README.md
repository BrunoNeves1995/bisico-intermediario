# Golang - Inicial ao Avançado

Repositório de estudos e exercícios do curso [Golang - Inicial ao Avançado](https://www.youtube.com/playlist?list=PL_vezUGkr_e7mPpg2RjWDgRWT2Fpo86Yt), criado pelo canal [DevRaiz](https://www.youtube.com/channel/UCemzVTEMrJmvCQ32m6e0_Vw).

## Sobre

O curso aborda Go desde os fundamentos até conceitos mais avançados, incluindo aplicações com framework, acesso a banco de dados, testes, relatórios, validação e implantação de serviços.

## Pré-requisitos

- Conhecimentos básicos de programação
- [Go](https://go.dev/dl/) instalado
- Um editor de código, como [Visual Studio Code](https://code.visualstudio.com/)

## Executando um projeto Go

Na pasta do projeto:

```bash
go run .
```

Para executar os testes:

```bash
go test ./...
```
